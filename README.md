# Silverline IT Infrastructure

## Project Overview
Silverline is a fictional small business used to simulate real-world IT infrastructure planning, deployment, administration, and troubleshooting.

This hands-on project documents my work building and managing a Windows-based business IT environment from the ground up.

## My Role
Simulated IT Administrator responsible for:
- Network planning and infrastructure design
- IT equipment research and procurement
- Windows Server administration
- User accounts and access permissions
- Workstation configuration and support
- Network troubleshooting
- Security monitoring and documentation

## Initial Project Budget
$7,500 (simulated procurement budget)

## Project Status
Phase 1 — Initial planning and procurement

## Project Goals
- Design a functional small-business network
- Deploy and configure Windows Server and client systems
- Implement centralized user and resource management
- Troubleshoot realistic IT support tickets
- Document technical decisions and lessons learned

## Documentation
Project documentation will be added as each phase is completed.

*This is an independent educational simulation, not employment at a real company.*
